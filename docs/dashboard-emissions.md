# CO₂ Emissions Analysis Dashboard

## Overview
Key influencer analysis and decomposition tree exploration of CO₂ emissions by vehicle type and attributes.

## Audience
- **Business users**: Explore emission drivers and compare vehicle segments.
- **Developers and team members**: Maintain the Power BI file, data source notes, and dashboard documentation.

## Skills Demonstrated
- Decomposition trees for hierarchical data exploration
- Key influencer visuals for factor analysis
- Advanced analytics and trend identification
- Narrative storytelling with multiple perspectives

## Key Insights
- Primary drivers of CO₂ emissions
- Emission trends by vehicle type
- Influencing factors and segments

## Business Questions Answered
- Which vehicle attributes are the strongest drivers of CO₂ emissions?
- How do emissions break down across vehicle segments?
- Which factors should be prioritized for deeper environmental analysis?

## Dashboard Pages
1. **CO₂ Decomposition Tree** — Hierarchical exploration of emission factors
2. **Key Influencers Analysis** — Main contributors to emissions
3. **CO₂ Emission Segment Analysis** — Detailed segment breakdown

## How to Use
1. Open `dashboards/emissions-analysis.pbix` in Power BI Desktop.
2. Use decomposition tree to drill down into contributing factors.
3. Review key influencers page for primary drivers.
