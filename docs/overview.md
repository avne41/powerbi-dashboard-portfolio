# Dashboard portfolio overview

This repository contains a Power BI portfolio project built as four distinct dashboard reports. Each dashboard demonstrates a different business analytics scenario and Power BI visualization technique.

## Audience
- **Business users** can use this overview to understand the purpose and business focus of each dashboard.
- **Developers and team members** can use this overview to understand how the dashboard collection is organized.

## Dashboards
- Global Sales Performance Dashboard — sales performance and category-based analysis
  - Skills: report layout design, KPI cards, category filtering, trend analysis, and comparative visuals.
  - Business focus: category performance, sales trends, and regional comparison.
- CO₂ emissions decomposition dashboard — key influencers and decomposition tree analysis
  - Skills: decomposition trees, key influencer visuals, advanced analysis, and narrative storytelling.
  - Business focus: emission drivers, vehicle attributes, and segment-level exploration.
- Sales categorical analysis — product category insights with custom visual elements
  - Skills: custom visuals, slicers, dynamic filtering, product segmentation, and interactive design.
  - Business focus: product segmentation, category/color filtering, and drill-down analysis.
- World population dashboard — demographic and population trends with mapping and Q&A features
  - Skills: map visuals, demographic analytics, trend forecasting, and Power BI Q&A support.
  - Business focus: geographic comparison, demographic trends, and natural-language exploration.
