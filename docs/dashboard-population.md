# World Population Dashboard

## Overview
Demographic and population trends analysis with mapping and natural language query support (Q&A visual).

## Audience
- **Business users**: Explore population trends, geographic patterns, and natural-language questions.
- **Developers and team members**: Maintain the Power BI file, data source notes, and dashboard documentation.

## Skills Demonstrated
- Map visuals for geographic analysis
- Demographic data exploration
- Power BI Q&A natural language support
- Time-based trend forecasting
- Multi-visual correlation and insights

## Key Metrics
- Global population trends
- Regional demographic breakdowns
- Population growth rates
- Age and gender distribution

## Business Questions Answered
- Which regions show the most notable population trends?
- How do demographic patterns compare across geographies?
- What questions can be explored quickly using natural language Q&A?

## Dashboard Pages
1. **Main Dashboard** — Global overview with maps, trends, and Q&A

## How to Use
1. Open `dashboards/world-population.pbix` in Power BI Desktop.
2. Explore geographic trends via the map visual.
3. Use the Q&A visual to ask natural language questions about the data (e.g., "Population by region over time").
4. Review trend lines for historical and forecasted population patterns.
