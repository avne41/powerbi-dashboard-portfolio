# Sales Categorical Analysis Dashboard

## Overview
Product category and color-based analysis using custom visuals and dynamic slicers for interactive exploration.

## Skills Demonstrated
- Custom visual integration
- Dynamic slicer setup and interactions
- Product segmentation and filtering
- Interactive report design
- Chiclet slicers for improved UX

## Data Sources
- **Source type**: Not documented yet
- **Location**: Not documented yet
- **Tables**: Products, Sales, Categories, Colors
- **Last updated**: Not documented yet

For guidance, see [Docs README](README.md#how-to-add-data-sources)

## Key Dimensions
- Product Category
- Product Color
- Sales Performance by Category
- Detailed product breakdowns

## Business Questions Answered
- Which product categories stand out in the sales mix?
- How do color and category filters change the view of performance?
- Which products or segments deserve drill-down analysis?

## Dashboard Pages
1. **Product Category & Color** — Overview and category-level analysis
2. **Details** — Drill-down into individual products and metrics

## How to Use
1. Open `dashboards/categories-analysis.pbix` in Power BI Desktop.
2. Use category and color slicers for filtering.
3. Navigate to Details page for granular analysis.
4. Click action buttons for dynamic interactions between pages.
